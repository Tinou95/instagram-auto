# instagram-auto
Publie un post par jour à 18h (Paris) sur @chevaliere.pour.homme.
- `file-attente/NN/` : `image.jpg` (4:5), `url.txt` (adresse publique), `legende.txt`. Le plus petit numéro part en premier.
- `publies/` : posts déjà publiés + `journal.txt`.
- Secret GitHub `FB_TOKEN` : jeton Facebook/Instagram (expire ; à renouveler avant ~60 jours).
- Test à blanc : onglet Actions > « Publier sur Instagram » > Run workflow (case « dry » cochée).
